Лабораторная работа №1. Чётный вариант: CMYK — RGB — HSV.

Откройте dist/index.html двойным щелчком в браузере.
Сервер, установка библиотек и интернет не нужны.

index.html — интерфейс; style.css — оформление; app.js — расчёты.
RGB и CMYK: числовые поля, ползунки, системная палитра по кнопке выбора цвета.
HSV: числовые поля, ползунки, системная палитра и цветовой квадрат.
Все три модели автоматически пересчитываются.
CMYK использует учебную формулу без ICC-профиля.

Проверка формул:
  dist/colors.js — общий модуль математических преобразований.
  tests/colors.test.cjs — 40 юнит-тестов, включая независимые эталоны.
  tests/reference.json — эталоны Python colorsys; Python для тестов не нужен.
  VALIDATION.md — результаты проверки и ограничения учебного CMYK.

Для запуска тестов нужен Node.js 18 или новее. Установка пакетов не нужна.
Из папки color-lab выполните:
  node --test tests/colors.test.cjs
или:
  npm test

Собрать один автономный HTML:
  node scripts/build.cjs
Результат — standalone.html. Для открытия исходного dist/index.html
Node.js не нужен: JavaScript исполняется браузером.
