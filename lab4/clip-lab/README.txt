Лабораторная работа № 4. Алгоритмы отсечения отрезков

Запуск приложения:
  Откройте lab4/index.html в браузере (сервер и сборка не требуются).

Реализованные алгоритмы:
  1. Алгоритм Лианга — Барски (отсечение отрезков прямоугольным окном).
  2. Алгоритм Кируса — Бека (отсечение отрезков выпуклым многоугольником).

Формат входного файла для прямоугольного окна:
  n
  x1_1 y1_1 x2_1 y2_1
  ...
  x1_n y1_n x2_n y2_n
  xmin ymin xmax ymax

Тесты, бенчмарк, рисунки и сборка (требуется Node.js >= 18):
  npm test
  npm run bench
  npm run figures
  npm run build -- ../index.html
