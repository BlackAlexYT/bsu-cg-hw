Лабораторная работа №3: базовые растровые алгоритмы.

Откройте dist/index.html (или ../index.html — то же одним файлом) в браузере.
Сервер, установка библиотек и интернет не нужны.

index.html, style.css — интерфейс; app.js — логика интерфейса;
raster.js — все алгоритмы и замер времени.

Алгоритмы:
  пошаговый (y = kx + b с округлением);
  ЦДА (приращения Δx/L, Δy/L);
  Брезенхем для отрезка (целочисленная ошибка e);
  Брезенхем для окружности (ходы H, D, V по знаку Δ, δ, δ');
  дополнительно: Кастл — Питвей (строка ходов s/d через алгоритм Евклида)
  и сглаженная линия Ву.

Привязка к сетке: пиксель (x, y) — клетка 1×1 с центром в целой точке (x, y),
линии сетки идут по полуцелым координатам, ось y направлена вверх.

Интерфейс: координаты вводятся в поля или щелчками по сетке; колесо мыши —
масштаб, перетаскивание — сдвиг. Под сеткой — таблица вычислений по шагам
для текущей фигуры и кнопка замера времени.

Проверка (Node.js 18+, из папки raster-lab):
  node --test tests/raster.test.cjs      (или npm test) — 14 тестов
Замер времени для отчёта:
  node scripts/benchmark.cjs
Рисунки для отчёта (TikZ в ../report/fig):
  node scripts/report-figures.cjs
Собрать один автономный HTML:
  node scripts/build.cjs ../index.html
