Лабораторная работа №2. Вариант 14:
локальная пороговая обработка + обнаружение точек, линий и перепадов яркости.

Откройте dist/index.html двойным щелчком в браузере.
Сервер, установка библиотек и интернет не нужны.

index.html, style.css — интерфейс; app.js — логика интерфейса;
imaging.js — все алгоритмы; gallery.js — встроенная база изображений.

Методы:
  локальная пороговая обработка — Ниблэк и Саувола;
  точки — лапласовская маска 3×3;
  линии — четыре маски направлений (0°, 90°, ±45°), светлые или тёмные линии;
  перепады — градиент по разностям (|Gx| + |Gy|) и лапласиан гауссиана (маска LoG 5×5).
Перед любым методом можно включить сглаживание Гауссом.
Свои изображения открываются кнопкой или перетаскиванием; цветные
переводятся в полутона, большие уменьшаются до 640 пикселей по длинной стороне.

База изображений — папка images (PNG). У изображений для бинаризации есть
эталон *-truth.png, по нему интерфейс считает F1. Изображения синтетические:
так известен правильный ответ. Генератор: scripts/generate-images.py
(нужны numpy и opencv-python). После изменения картинок пересоберите галерею:
  node scripts/build-gallery.cjs

Проверка:
  tests/imaging.test.cjs — 50 тестов: сверка с OpenCV (filter2D, GaussianBlur)
  и scikit-image (threshold_niblack, threshold_sauvola) на случайных
  изображениях и ручные примеры. Эталоны — tests/reference.json,
  генератор — tests/generate-reference.py; Python для запуска тестов не нужен.
  Запуск из папки segment-lab (Node.js 18+):
    node --test tests/imaging.test.cjs
  или
    npm test

Сравнение методов на базе (таблицы для отчёта):
  node scripts/evaluate.cjs
Рисунки для отчёта (в ../report/fig):
  node scripts/report-figures.cjs

Собрать один автономный HTML:
  node scripts/build.cjs
Результат — standalone.html.
